# 回归本真

随笔，写于 25-12-26。真心感谢学长——客观上看男性女性都可以叫学长？我也不确定——以及把我从困局里轻轻推了一把的那些人。

曾经我也蛮热爱文字。儿时写过不入流的小说（甚至发表过一本，现在看来确实……），也写过诗集，都是打油诗，竟然被家里先生「偷」去装订成书册。其后不曾细细雕琢，也未再学大师们的技巧，平日对写写说说仍有兴致。

儿时不善言辞，较少社交。闲暇无非看书，或者发呆。幼时那份想象力，渗透进后来的点滴。很感激孩提留下的幻想：十余年独处，不觉孤独，时间从指尖划过，余热犹存——最本真的无忧无虑。

少年本该广交天下友。可惜从小父母不在身边，小学初中惯于一方天地，很少与人打交道，成绩马马虎虎，进了一所相对不错的高中。高中和大学初期的事，若有缘分再写。

兴许是惯于独处，也兴许是姐姐带大的，性格不像典型小男孩，做事尽全尽美，愿意给生活仪式感，在独处里体悟静谧。恰如旷野奔跑，恰似林海漫步，夕阳散落花海——回归原始，找寻心中宁静，那片可以全然沉浸的热爱之地。一种极致的浪漫。

恰似「看山不是山，看水不是水」：找到热爱并走下去，周围就是心中的宁静。又「看山还是山，看水还是水」：带着热爱回到现实，寻自己的一片天地。「少年自有青云志」，人总归离不开社会，但行前路而莫问前程。纵使年少失意，怎负少年轻狂？羽化成蝶方可升生不息。

「回首处，弯弓北望射天狼」——去找那个让你回首一鸣的契机。行路途旁，年少珍贵，感情珍贵，缘分珍贵。

「少年时驰骋的风，比黄金还贵。」
「若再许我少年时，一两黄金一两风。」
「千里路途我只陪你一程，从此风雪艳阳我都不再过问。」

大抵就像这样。偶然念起曾经的「我」，也算不忘初心。文字于他人或许只是鸡汤，于我是把零散的自己写得更紧密。抒情亦如此：热爱不一定非要成绩，写给自己也可以。

「彼方尚有荣光在，拾光许我三两清。」

至此，终于为我所有格言、所有网名，编凑了一篇小散文。一点灵感源自星楚学姐，也鸣谢学生会陶小友的文字指点。
