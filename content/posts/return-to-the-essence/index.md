# 回归本真

真心感谢下学长（客观上看，男性女性都可以叫学长?Ľ?Ľ主要我也不确定学长性别?¥）?Ě?Ě?Ě

曾经我也是蛮热爱文字的，儿时便写过很多不入流文章，小说呀（甚至还发表过一本?¥虽然现在看来确实...），也曾写过诗集（虽然都是打油诗 但竟然被我们家先生"偷"去装订成书册了），虽说其后不曾细细雕琢打磨文字，也未再学习大师们的语言以及写作技巧，却平日对写写说说也颇有几分兴致。
    儿时不善言辞，故而较少社交，闲暇之余，无非是看看闲书，亦或...发发呆？幼时那份想象力，肆意蔓延于那段空白的人生， 渗透浇筑了未来点滴——很多时候真的很感激孩提时期余留下的那些幻想，曾经十余年独处时光，沐浴于沉浸的岁序，不觉孤独，时间悄然从指尖划过，不觉痕迹，那份余热犹存——最本真原始的无忧无虑。
    相逢意气为君饮，系马高楼垂柳边。少年时期本该是广交天下友，寻梦种春秋的大好时光，可惜亦是从小父母不在身边的缘故吧，学生时代，尤其是初中小学，便惯于沉浸于自己一方天地，很少与他人打交道，不过也因此，个人成绩也算是马马虎虎，顺利进入相对不错一所高中。
    高中以及大学初期发生事情不可谓不多，若有所缘分，再加以分享罢。
    兴许是当年惯以独处，也兴许是儿时大多都是姐姐带的我吧，个人性格不像小男孩，或多或少留有些许小女孩气息；很多时候做事都倾向于尽全尽美，更多时候也愿意为生活赋予仪式感，于独处中体悟那种极致的静谧。
    恰如与旷野中肆意奔跑，恰似漫步与茫茫林海，周围鸟雀欢腾，四周繁华似锦，阳光斜斜落下，夕阳光辉散落于朦胧花海，烂漫恬静，不着烟火气息，不忆世俗困境。回归原始，回归自然本性，找寻心中宁静，那片你可以肆意追逐热爱之地，那片你可以全然沉浸于眼前热爱之地... ...
    一种极致的浪漫。
    恰似"看山不是山，看水不是水"——当你找寻到心中那份热爱，并明确方向走下去，沉浸下去，周围就是你理想的那份心中宁静之地，回归那份热爱的本真，不困顿于世俗点滴。
    "看山还是山，看水还是水"，带着热爱向前，回归现实，去找寻自己于世间一片天地，怀揣抱负理想，无须他人证明什么，"少年自有青云志，当属天下第一流"，人总归是离不开社会的，带着理想和热爱追逐自己那个梦，少年载梦而归，只待今朝，韬光养晦而有所作为，但行前路而莫问前程。纵使年少失意，有怎负少年轻狂？又怎负少年热爱？羽化成蝶方可升生不息！
    "回首处，弯弓北望射天狼"——去寻找那个让你回首一鸣惊人的契机。找寻那份机遇。
    而行路途旁，当属年少珍贵，当属感情珍贵，当属缘分珍贵。念想珍惜，顺遂缘分。
    "少年时驰骋的风，比黄金还贵"
    "若再许我少年时，一两黄金一两风"
    "千里路途我只陪你一程，从此风雪艳阳我都不再过问"

大抵就像这样罢，也算缘分使然，偶然契机右念想起曾经的"我"，兴许也算是不忘初心吧，很多时候，不，是太多时候，文字总有那些说不出的魅力，于他人，那些描绘或许毫无价值，兴许只是枯燥的描绘或是堆砌鸡汤罢了，亦或可以共鸣于文字间的碰撞组合，联想到自己某些事情，或许能想通什么，这些不必去论，文字传情达意，抒情抒己情，我写难得清静，我写我零散的文字，写我零散的自己，便觉得自我更紧密了，于我的意义，倘若他人有感，亦是他人的感悟。太多时候，见识的更多了，不拘泥于过去式了，便念头通达了，也因此，读书看理论，拓展认知边界，实践内化理论总结理论，拼凑曾经零零散散的内容，整合了，便逐渐自然了，熟悉了。
    抒情亦如此吧。
    很多时候，热爱不一定非得有个啥子成绩，写文章也可以是热爱，那有时疯疯癫癫也好，写给自己，受众自己，追寻自己，谁言抒情一定要有像外的价值？
    “彼方尚有荣光在，拾光许我三两清”

至此，终于为我所有格言，所有网名，编凑了一个小散文。（补充，其中一点灵感源自星楚学姐，郑重鸣谢，也鸣谢学生会陶小友文字指点，追忆起很多曾经点滴，也打破了目前一个困局，感谢缘分）
