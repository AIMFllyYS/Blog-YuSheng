## 一、本文档的位置

`frontend-design.md` 管全站 token 与通用规则，`routing.md` 管路由与面板语义。博客两个页面**具体长什么样、怎么动**以同目录 [blog-reader-prototype.html](./blog-reader-prototype.html) 为 **1:1 对标**；本文只解释决策理由、待确认项与实现归属，不为实现另写一套外观。

原始产品构思中的三处设计在整理成规范时被压缩掉了，本文负责恢复并写实：

1. 左侧目录的双模式设计（tab 切换、常规模式对标飞书、图形模式是文章的骨架屏缩略：一级标题 + 按篇幅增减的正文骨架条）；
2. 顶部导航渐隐的**触发条件**；
3. 右侧工作区**收起后变成右侧悬浮小笔**（钉在窗口右侧，不是移动端抽屉入口）。

在此之上本文另外定型了规范里没有的东西：双层滚动架构（3.1）、进页书册遮罩（3.2）、导航命中区（4.4）、Agent 页签的外壳形态（9.1.1）、右栏骨架懒载与缓出（9.3）、整幅页尾评论区（9.5）、滚动条样式（11.1），以及左栏不可收起这条决定（5.3）。

## 二、设计气质

| 关键词 | 具体含义 |
| --- | --- |
| 舒缓 | 默认宣纸黄、宋体正文、宽行距；动效是阻尼、慢、ease-out（`--ease-damp`），连续量约 0.035 追赶。不用高饱和色块，不用弹跳/回弹 |
| 书卷 | 与首页线装古籍世界观连贯；绳索、卷轴、书签、便签是全站可复用的视觉语汇，不按页面另做 |
| 图文并茂且可交互 | 正文不只是文字：公式、图表、画布、SVG、视频、音频、问答都是一等公民 |
| 安静优先 | 装饰不抢正文；导航、工具条、面板在不使用时退到边缘或消失 |

## 三、页面骨架

```text
┌───────── 绳挂导航（渐隐，z=nav） ─────────┐
│  羽升卷轴   博客书签   导出 分享 编辑   主题 音效 设置  │
└──────────────────────────────────────────┘
┌──────────┬────────────────────────┬──────────────┐ ┐
│ 左：目录  │ 中：正文               │ 右：工作区    │ │
│（常驻）   │                        │ 评论/注释/Agent│ │ 正好一屏高
│ tab:     │ 划词 → 浮动工具条       │ tab 切换      │ │
│ 目录/图形 │ 注释高亮 ↔ 右侧卡片    │ 可收起        │ │
└──────────┴────────────────────────┴──────────────┘ ┘
～～～～～～～～～～ 波浪 ～～～～～～～～～～～～～～  ← 左右栏在此终止
┌──────────────────────────────────────────────────┐
│            整幅页尾评论区（跨整页宽度）             │
└──────────────────────────────────────────────────┘
   ◍ 目录球（仅移动端）           ◍ 右侧小笔（z=floating）
```

| 区域 | 桌面默认 | 收起形态 |
| --- | --- | --- |
| 顶部导航 | 隐藏（指针进入中栏顶部感应区才出现） | — |
| 左侧目录 | 展开，常规模式 | 不可收起；移动端降级为抽屉 + 左下球 |
| 中间正文 | 始终可见 | — |
| 右侧工作区 | 展开，停在「注释」页签 | 右侧悬浮小笔（纯图标 + 手写条数） |
| 页尾评论区 | 在一屏之下，正文到底后继续下滚才拉出 | — |

三栏之间有可拖动分隔线；正文区有最小宽度，拖动不能把正文挤到不可读。

### 3.1 双层滚动

这一页有两层滚动，页尾是三栏的兄弟节点。首屏只显示三栏，页尾不得探进视口。

1. **栏内滚动**：三栏各自 `height: 100vh; overflow: auto`，读正文时滚的是中栏。左右栏可设 `overscroll-behavior: contain`；中栏不能设，否则滚不到页尾。
2. **读到尽头先收口**：中栏到底时左右栏坐实、底边浪升起。这只是视觉，不拦截滚轮。
3. **继续下滚拉出页尾**：到底之后，在左栏、中栏或右栏继续下滚，都把滚动交给文档，三栏整体上移，页尾进入视野。不要再设闸门或 `preventDefault`。右栏「去页尾评论区」仍可直接跳到页尾。

### 3.2 进页书册遮罩

进入 `/blog/` 或 `/blog/<slug>/` 时，三栏尚未揭开之前先盖一层全屏书册加载。这是路由级一次，不是页内装饰。

- 形态**严格**跟 Uiverse Nawsome 原作（`curly-goose-54`）：类名 `.loader`，六页 SVG，第 1 页常开在左、第 6 页常开在右，只有第 2–5 页做 `page-2`…`page-5` 翻页；不要自造 `page-6`，不要改 `backface-visibility` 或字号。
- **只改原作的四个颜色变量跟主题**：`--background` ← `--accent` 渐变，`--shadow` ← accent 28% 透明，`--page` / `--page-fold` ← `--scroll-paper` 的 36% / 52% 透明（原作是半透明白页），`--text` ← `--ink-muted`。禁止沿用原作蓝紫，也禁止把书页画成不透明色块。
- 层级走 `--z-boot`（60），压过通知与弹窗。揭开后移除节点，不占后续交互。
- 主题切换、打开右栏、导出、划词等页内操作**不再重放**这层遮罩。
- 书册四周的空白用 **Pretext Two** 铺一层浅浅的大字印章：先量「羽升」再按视口中心铺格，绕开中间的书，微微倾斜；`--accent` 极浅，并带一层软光。单页原型从 `esm.sh/@chenglou/pretext@0.0.8` 按需 `import()`；断网或没有 `Intl.Segmenter` 时退回几个居中大字，不挡翻书。
- 原型用约 2 秒示意。落地时等首屏关键内容就绪再揭开，但至少让翻页被看见一拍；不要假忙超过约 3 秒。
- `prefers-reduced-motion` 下取消翻页，几乎立刻揭开；印章仍可静静在。

## 四、顶部绳挂导航

### 4.1 形态

- 一条横贯顶部的绳索（两条 SVG 曲线叠加，细线在下形成质感），挂件从绳上垂下，绳长不等，形成参差。
- 挂件落在中栏幕布上，不骑到左栏目录或右栏页签上；右侧一组再往里收一截，避免贴住工作区。
- 明确**不使用**长方形卡片式导航条。
- 挂件形态复用书卷语汇：品牌用卷轴（带轴头）、路由入口用书签（下缘尖角）、开关类用圆形挂牌。
- 悬停时挂件轻微上浮（`--dur-fast`），不摆动到影响点击。

### 4.2 挂载项

| 挂件 | 形态 | 行为 |
| --- | --- | --- |
| 羽升 | 卷轴 | 回首页 |
| 博客 | 书签 | 回 `/blog/`。桌面 hub（`/`、`/blog/`、`/notes/`、`/works/`）与阅读页都出现；移动端绳上不挂 |
| 随笔 | 书签 | 去 `/notes/`。只出现在桌面 hub，阅读页隐藏 |
| 作品集 | 书签 | 去 `/works/`。只出现在桌面 hub，阅读页隐藏 |
| 导出 | 书签 | 展开二级菜单（见第十二节）；仅阅读页 |
| 分享 | 圆挂牌 | 移动端调用系统分享，否则复制链接并 toast |
| GitHub | 圆挂牌 | 新标签打开 [AIMFllyYS/Blog-YuSheng](https://github.com/AIMFllyYS/Blog-YuSheng)；唯一使用实心图标的挂件 |
| 编辑 | 书签 | 仅作者可见；P3 前不出现，不做灰色假入口 |
| 主题 | 圆挂牌 | 单击循环切换主题 |
| 音效 | 圆挂牌 | 开关，默认关 |
| 设置 | 圆挂牌 | 就地弹出小面板（主题四选 + 音效） |

挂件图标统一 `fill: none` + `stroke: currentColor`，只有 GitHub 用官方实心标记（品牌标识不应被改成线稿）。

### 4.3 渐隐规则

导航默认不可见，正文占满视野。

| 显示条件 | 说明 |
| --- | --- |
| 指针进入中栏顶部感应区 | **唯一的鼠标触发**：纵轴只认顶部约 88px（挂件带实际高度），横轴只认中栏正文，不含左栏、右栏和两条分隔线 |
| 键盘聚焦到导航内任一控件 | 保证键盘可达，不能只靠鼠标 |
| 页面刚加载 | 短暂显示后自动淡出，用于告知导航存在 |

| 隐藏条件 | 说明 |
| --- | --- |
| 指针离开感应区且不在导航实体上 | 短延时后淡出 |
| 开始滚动 | 立即淡出 |
| 窗口失焦 | 淡出 |
| 页尾评论区占据视野 | 三栏已滚出屏幕，导航与悬浮球一并退场 |
| 面板/菜单打开时 | 不淡出，保持可见直到关闭 |

原始构思里写的是"鼠标向上移动即唤出"。原型实测这条规则不能用：正常阅读时指针会不断微幅上移，导航几乎等于常驻显示，反而破坏了"正文占满视野"的初衷。因此改为只认顶部感应区。左右栏顶部再排除出去：点目录挂签或右栏页签时不该把绳挂导航拽下来。

### 4.4 命中区（必须遵守，否则会出可用性事故）

导航是一条**横贯整屏、约 88px 高的固定层**，正下方压着左右栏的页签和正文的顶部。因此：

- 导航容器、绳索 SVG、挂钩、弹性占位一律 `pointer-events: none`。
- 只有**挂件本身**（卷轴、书签、圆挂牌）在导航可见时 `pointer-events: auto`。
- 弹出面板在打开时才 `pointer-events: auto`，关闭状态不得拦截。
- 顶部感应区元素同样 `pointer-events: none`，它只是把 88px 这个数字写在结构里。真正的唤出范围由脚本按中栏左右边界裁切，左右栏顶部不会唤出导航。

违反任何一条的后果都不是"样式不好看"，而是左右栏顶部的页签点不动、正文顶部无法划词——而且因为导航是渐隐的，排查时很难想到是它挡住的。

### 4.5 挂件悬停提示

图标挂件（以及「羽升」「博客」「导出」）悬停或键盘聚焦时，在挂件正下方出现一张**小便笺**：`--scroll-paper` 底、细边框、轻微倾斜、一句说明这个按钮干什么。提示本身 `pointer-events: none`，不扩大命中区。菜单已展开（`aria-expanded="true"`）时提示隐去，避免叠在导出/设置面板上。

`prefers-reduced-motion` 下取消淡入淡出，用直接显示/隐藏。

## 五、左侧目录（恢复完整设计）

顶部一对**常驻挂签**（目录 / 图形）对等切换，切换记住用户选择。挂签从短绳垂下，绳长参差，选中时缓落、未选中回位。切换时先出约 380ms 短骨架再换真内容，不要瞬间翻面。顶部绳挂导航唤出时，左挂签把绳子加长、垂到挂件带下方，两套挂件不叠在同一高度。目录模式下挂签与正文幕布之间留一点空隙，不要贴着分隔线。

### 5.1 常规模式（对标飞书左侧目录）

- 纯文字层级树，靠缩进和字号区分级别，不用图标堆装饰。
- 目录文字与中栏幕布之间留一截空隙，不要贴着分隔线。
- 每项左侧有一条细指示条；**当前所在章节**的指示条使用 `--accent`，其余为 `--line`。
- 有子项的条目带一个小三角，可折叠；折叠状态记忆。
- 悬停显示浅色底；当前项底色比悬停更明确一档。
- 长标题单行截断并在悬停时显示完整文字。
- 滚动正文时当前项自动跟随，但用户手动滚动目录后暂停自动跟随若干秒，避免抢夺控制。

### 5.2 图形模式（对标画布小地图）

原始构思的参照物是 React Flow 画布右下角那块小地图：**把整篇文章缩略成一张可点击的图**。

- 进入图形模式后，左栏浅色底、右边框、分隔线与**滚动条**一并隐去，不再读成一条可滚动导航。画布铺在页面 `--bg` 上，不套 elevated 卡片，也不再单独铺一层点阵底。
- 只保留常驻挂签与图形本身；常规目录树在此模式不出现。
- 节点悬停提示挂在 `body` 上的独立层（`--z-overlay`），不放在左栏滚动容器里，避免被 `overflow` 裁切或被正文盖住。移入即出现，移出即隐去。
- 图形是文章的**骨架屏缩略**，不是第二棵标题树。只画**一级标题 + 正文骨架**，不把二三四级拆成独立节点。标题行统一大小；正文用堆叠骨架条表示该节篇幅（含子集），像加载占位，不是一块被拉高的空卡片。比例尺整体收小，但不牺牲篇幅对比。
- **条数跟文字走**：篇幅 = 该节去空白字数。一篇文章内部做相对映射——最短的节最少条、最长的节最多条，中间按字数线性插值，范围 2–8 条。末条宽度吃余数，避免两节落在同一整数档时完全一样。禁止开方或其它把各节压成同一档的压缩。
- 节点内不写完整标题，悬停时才浮出真实标题。
- 三类嵌入微标（自定义标签 / 图片 / 思维导图）只挂在一级标题行右侧，各用不同语义色。音频不进微标。
- 节点之间用一条贯穿的主干线 + 横向接头连接，从上到下流动。
- 有一个**虚线视口框**（`--accent` 虚线 + `--highlight` 填充）标示当前阅读位置，随正文滚动移动。它只负责定位，高度不随章节篇幅缩放。
- 点击任意节点跳到正文对应位置；点击视口框外的空白区域不产生跳转。
- 节点可带角标表示该章节内的注释数量。
- 图例不占骨架流。左下角一枚常驻书签，点击后缓出解析小卡片：当前视窗 / 标题长度 / 条数即篇幅。再点书签或把卡片向下拉即收起。骨架较长时卡片覆盖在节点上，边缘做毛边。

### 5.3 共同规则

- 两种模式消费同一份目录数据，不各自解析正文。
- 两种模式都支持键盘上下移动与回车跳转。
- **左栏不支持收起**。桌面端常驻，只能拖动分隔线调宽窄；目录是长文的主要导航手段，让它可以整体消失得不偿失，也省掉了"收起态左球 / 移动端左球"两种形态并存的歧义。
- 移动端（≤1024px）左栏降级为抽屉，由左下悬浮文字球唤出——这是可达性兜底，不是"收起"功能。

## 六、中间正文

### 6.1 版式

- 单列，最大宽度受限（约 68–76 个中文字符宽），居中。
- 宋体正文，行高宽松；段间距大于行距，形成呼吸感。
- 标题层级靠字号与字重区分，不加下划线或色块。
- 页首为标题区：标题、日期、预计阅读时长、标签；标题区下有一条细分隔线。

### 6.2 正文中可以出现的内容块

| 块 | 视觉规范 |
| --- | --- |
| 段落/列表/引用 | 引用用左侧竖线 + 次要文字色，不用大引号图形 |
| 行内与块级公式 | 块级公式居中独立成行，左右留白；行内公式不破坏行高 |
| 代码块 | 等宽字体、浅底、圆角、右上角语言标签与复制按钮 |
| 表格 | 细线、表头浅底、横向可滚动而不撑破正文列宽 |
| 图片 | 圆角 + 细边 + 图注居中次要色；必须占位防抖动 |
| 视频 | 封面 + 居中播放按钮 + 标题栏；不自动播放 |
| 音频 | 横条播放器 + 标题 + 时长；可选转写折叠区 |
| Mermaid 图表 | 与图片同一卡片外观；深浅主题下线条颜色走 token |
| Canvas 组件 | 卡片内嵌，右上角标注「交互」徽标 |
| SVG | 与图片同一外观，矢量优先 |
| 本地 HTML | 卡片内 iframe，卡片头部标注「沙箱运行」徽标与标题 |
| 网页嵌入 | 无法嵌入时降级为预览卡片：标题 + 域名 + 打开链接 |
| 选择题/填空题 | 卡片形式，题干 + 选项 + 「检查」按钮；判分后显示对错与解析 |

### 6.3 组件卡片统一外观

所有注册组件共用一套卡片外壳：细边框、`--bg-elevated` 底、圆角、顶部一行细标题栏（左标题、右徽标）。这样正文里出现十几种组件时视觉仍然是一体的。

### 6.4 降级卡片外观

组件失败时**不留空白也不白屏**，显示统一降级卡片：

- 虚线边框区分于正常卡片；
- 一句中文说明发生了什么（例如「这个图形组件没有加载成功」）；
- 可选的替代内容（快照图、原始链接、文字说明）；
- 角落显示错误码与关联 ID，供反馈使用。

## 七、划词工具条

- 在正文中完成选择后，工具条浮现在选区上方居中；贴近顶部时翻转到下方。
- 固定三个动作：**复制 / 询问 / 注释**。不提供「评论」——文章级评论只能从右栏评论页签或文末评论区发起。
- 「询问」在 Agent 未接入前**不显示**，不做灰色假按钮。原型中它可见，用于演示上下文传递。
- 点「注释」：右侧切到注释页签、输入框获得焦点、选中文字作为引语出现在输入框上方。
- 点「询问」：右侧切到 Agent 页签，选区与当前标题路径写入上下文条。
- 触摸端：跟随系统选择手柄出现，按钮尺寸不小于 44px，避免与系统菜单重叠。

## 八、注释高亮与双向定位

- 有注释的原文使用 `--highlight` 底色，下缘一条 `--annotation` 细线，不使用粗色块。
- 同一处存在多条注释时只显示**一个**高亮，右上角小角标显示数量，避免叠色不可辨识。
- 点击高亮：右侧对应卡片滚入视野并短暂强调（背景轻微闪一次）。
- 点击右侧卡片：正文滚动到目标并同样强调。
- 失锚注释：卡片保留在列表中，显示「原文位置已变化」状态与原始引语，正文中不显示高亮。

## 九、右侧工作区（恢复收起形态）

### 9.1 三个页签

| 页签 | 内容 | 排序 |
| --- | --- | --- |
| 评论 | 针对整篇文章的线程 | 按时间 |
| 注释 | 针对选区的线程 | 按正文位置，同位置按时间 |
| Agent | 未来的选区询问外壳 | — |

页签切换不是瞬间换面：先出与目标页签同构的短骨架（约 400ms），再淡入真内容。这是微懒载，不要套整栏 `--dur-reveal`。栏已收起或正在展开/收起时，只换页签、不再叠一段骨架。

### 9.1.1 Agent 页签的外壳形态

接入模型前它仍然要有完整外壳，否则无法判断三栏宽度和上下文传递是否成立。自上而下：

1. **上下文条**：一行虚线框，写清本轮会带出去的东西——文章标题、标题路径、当前选区。划词点「询问」时这条实时更新。这是 Agent 页签存在的理由，不是装饰。
2. **对话区**：用户气泡右对齐走 `--highlight` 底，分身气泡左对齐走 `--bg` 底；分身回答下方可挂一条 `--accent` 左边线的**引用来源**（指向正文某个标题路径），把"答案从哪来"显式化。等待中用三点呼吸动画。
3. **建议提问**：一排胶囊 chip（解释这一段 / 找出论证薄弱处 / 生成三句摘要 / 出两道自测题），降低冷启动成本。
4. **输入区**：`position: sticky` 贴底，回车发送、Shift + 回车换行；下方一行小字声明"上下文只传选区 + 标题路径 + 文章元数据，正文正本不被改写"。

未接入期间对话内容明确标注为示意，输入区可见但不产生请求；不做灰色假按钮。

### 9.2 默认状态（本文新定义）

- 桌面端默认展开，停在**注释**页签——注释是本站相对特殊的能力，默认展示它比默认展示评论更能说明产品。
- 首次访问后记住用户最后停留的页签与展开状态。
- 面板展开不拉取数据；数据在页签真正可见时才请求。视觉上对应 9.3 的骨架：栏在动、内容还没到时只画肋骨，到位后再淡入真线程。

### 9.3 收起与右侧悬浮小笔

- 面板右上角有收起按钮；收起后面板宽度归零，正文自然变宽。**只有右栏可收起**（左栏见 5.3）。
- **展开 / 收起不是瞬间切换。** 栏宽用 `--dur-reveal`（约 780ms）缓出，内层再轻轻从右侧移入，不要弹跳或回弹。展开时先铺一层与当前页签同构的骨架（评论/注释是标题条 + 卡片肋骨，Agent 是上下文条 + 气泡），真内容在栏宽基本到位后再淡入；收起先把内容收成骨架，再把栏宽慢慢推回去。骨架条用百分比宽度，跟着栏一起变窄变宽。移动端抽屉共用这套骨架，只是外层改成从右侧滑入。
- 动画进行中忽略连点。左栏桌面端不参与这套收展。
- 收起后入口**必须留在窗口右侧**（`right` 钉死），不能因为左球隐藏就被 flex 挤到左边。
- 形态是**裸笔 + 手写数字**，没有圆底、没有胶囊、没有框。不写「批注」二字。
- 数字是**当前注释条数**，锚在**笔尖正下方**，与笔同一套手写描边，沿笔画慢慢写出（约 7 秒一圈），不要另做一套立体字。笔直立绘制，CSS 转到握笔姿势（笔尖朝左下、笔杆朝右上），默认绕笔尖微微晃动。
- 悬停解析出现在**整组笔+数字的正左侧**，走同一套笔迹：墨色手写字、细墨线，不要纸片卡片。右键弹出「运动 / 静止」。默认运动；选静止后笔停在 45°、数字常显。选择记在本地。`prefers-reduced-motion` 下按静止起。
- 左键仍打开工作区。不跟随正文滚动抖动。
- 移动端（≤1024px）右栏降级为抽屉，右侧小笔常驻作为唯一入口，点击从右侧滑出并带遮罩。桌面收起态与移动抽屉态是两种不同形态，共用同一支笔。
- 左下入口只在移动端出现，用于唤出目录抽屉，保持文字「目录」，不和右侧笔标抢图标语义。

### 9.4 卡片结构

每条评论/注释卡片自上而下：

1. 公开名称 + 作者/访客徽标 + 时间 +（可选）已编辑；
2. 注释卡片额外显示引语与标题路径；
3. 正文（走讨论档位渲染，可含 Markdown、代码、表格、公式）；
4. 底部操作：回复 / 编辑（仅自己）/ 删除；
5. 回复以缩进嵌套，最多五层，超出改为「查看更多回复」。

徽标只表达身份，不做等级、积分或认证层级。

### 9.5 整幅页尾评论区

右栏「评论」页签之外，页面底部另有一块评论区。两者是**同一份文章级数据的两个入口**，不是两套数据、也不是两套渲染。

#### 布局：它是页尾，不是"正文末尾的一段"

- 它跨**整页宽度**，是三栏容器的兄弟节点。波浪就是左右栏的终止线：波浪以下不存在目录栏、不存在工作区，整幅都是评论区。
- 底色与左右栏同为 `--bg-elevated`。这不是巧合而是必要条件——波浪的填充色也是 `--bg-elevated`，所以波浪扫过左右栏正下方时颜色连续，两栏看上去是溶进水里而不是被切断；只在中栏（`--bg`）那一段能看见明确的分界。
- 内容居中收口到比正文行宽略宽一档（约 54rem）。页尾不再受阅读行宽约束，但也不能通栏铺满变成表格感。

#### 波浪

- 三条路径：一条 `--highlight`（半透明强调色）的后浪、一条 `--bg-elevated` 的前浪、一条 `--line` 的发丝线勾出前浪波峰。两浪交错才有水面层次；单条只会读成一个圆角。
- 曲线要矮、波长要长，和三栏底边收口浪是同一条 path。禁止用 `scaleY` 把浪压成一条色带——那是衔接发硬的主因。
- 未进入页尾时不要负边距，避免浪探进首屏。进入页尾后再向上重叠栏底约 40px，左右栏底用渐隐溶进浪里。
- 阴影只留很浅的一层（约 `0 -2px 8px`），标题紧贴浪下，不要在浪和「评论」之间空出一大截。

#### 进入页尾

- 正文到底后先收口，继续下滚由滚动链拉出页尾。右栏互指链接也可直接跳到页尾。
- 展开量 `--reveal` ∈ [0,1] 按页尾顶边进入视口的比例计算。当前值每帧以约 **0.035** 追赶目标值（比右栏 `--dur-reveal` 略慢一拍），整块再上移、分层滞后加大，读起来像被阻尼拽上来。只驱动位移与透明度，**不压扁波浪，也不拦截滚轮**。点「去页尾评论区」用同一套阻尼滚动，人手一滚就让出。
- `--reveal` 越过约 0.62 时给 `body` 加标记，隐藏悬浮球与顶部导航。
- `prefers-reduced-motion` 下 `--reveal` 直接为 1，只保留波浪造型。

#### 内容

- 结构：标题 + 条数 + 排序（最新 / 最早）→ 一段说明两个入口关系的小字 → 输入框（含"内容会被 sanitize、禁用原始 HTML 与脚本"的提示）→ 线程列表 → 「加载更早的评论」。
- 只承载**文章级评论**。选区级注释不出现在这里，避免和正文高亮的位置语义打架。
- 卡片结构与 9.4 一致，字号放大一档，操作项多一个「引用」。
- 桌面端两者并存：右栏负责"边读边写"，页尾负责"读完再说"；右栏评论页签顶部给一条「去页尾评论区」的互指链接，明示是同一份数据。移动端右栏收起成球之后，页尾是主入口——这直接回答了第十五节关于移动端评论位置的待确认项。
- 分页增量加载，未展开的层级不参与首屏解析（见规格 13.4）。

## 十、分栏拉动与响应式

| 断点 | 布局 | 收起形态 |
| --- | --- | --- |
| >1024px | 三栏并列占满一屏，两条分隔线可拖动；页尾在其下 | 只有右栏可收起为右侧悬浮小笔；左栏常驻 |
| ≤1024px | 单栏正文占满一屏；页尾在其下 | 左右栏都变抽屉，从左下文字球 / 右侧小笔呼出，带遮罩 |

两个断点的页尾行为完全一致——页尾是页面级结构，不随分栏变化。

拖动规则：正文最小宽度优先保障，左右栏各有最小与最大宽度；双击分隔线恢复默认比例；拖动状态下不触发文本选择。

### 10.1 目录跳转与文档滚动

点击目录跳转时，若人在页尾，必须先把文档滚回顶部再在中栏内定位，否则会跳到一个被页尾遮住的位置。

## 十一、主题

沿用 `frontend-design.md` 的四套主题与语义 token：宣纸黄（默认）、浅蓝、米白、纯黑。

- 原始构思为**浅黄 / 米白 / 纯黑三套**，浅蓝是文档整理阶段新增的，是否保留见第十五节。
- 正文、组件卡片、代码块、高亮、面板、徽标一律走 token，禁止硬编码颜色。
- 主题切换使用 `--dur-slow` 全局颜色过渡，避免闪跳。

### 11.1 滚动条

四套主题都是低对比、连续色面，系统默认滚动条那条灰槽会在任何一套里都显得脏。

- 每套主题各出两个 token：常态与悬停时的滑块颜色（用 `--ink` 系的低透明度值，不引入新色）。
- **静止时完全透明**，指针进入可滚动容器才浮现一条无轨的细滑块；离开即隐去。
- 左栏目录模式与中栏：不用彻底隐藏——长文滚动位置是必要信息。所求的是"看不见但要得到"，静止透明、指针进入才浮现。
- **彻底不画滚动条的两处**：窗体最右侧（`html` / `body`，页尾那一层）和右栏工作区。右缘保持干净；页尾与右栏仍可滚轮滚动。图形模式的左栏同样彻底隐去。
- 同时写 `scrollbar-color`（Firefox）与 `::-webkit-scrollbar-*`（Chromium/WebKit）；滑块用透明边框 + `background-clip: content-box` 做内缩，避免贴边显粗。

## 十一之二、通知

全站轻量反馈只有这一种形态，原型里那些会自己往下落的纸质通知就是它。评论发布成功、注释写下、链接已复制、导出完成、登录链接已发送，全部走它，不另做右上角角标或系统 snackbar。

- 外观：`--scroll-paper` 底、细边框、顶部一条半透明胶带、右下角折页、轻微倾斜。这是便签，不是胶囊条。
- 结构：一行字号更小的「通知」抬头 + 一句正文。
- 物理：从视口顶出现，受重力落到视口最底部，然后隐去；下落时纸面轻微摇摆。左右落点随机，起始高度相同。
- 多张：每次成功触发都生成一张新便签，已在下落的不替换、不停掉。
- 冷却：整套通知默认 1 秒冷却，冷却期内不再生成，防止高频点击。
- 悬停：立刻停住；若已经开始隐去，悬停会把它重新拿住。移开后继续下落。只作用于被悬停的那一张。
- 点击：撕成不规则碎片散开，再隐去。撕碎用 `clip-path` 碎片，不引入 Three.js。
- `role="status"`，不抢焦点；可见时可点、可悬停。
- 需要用户决策的失败（导出不完整、删除确认）走弹窗或就地状态，不塞进通知。
- `prefers-reduced-motion` 下取消下落与撕碎，只做显隐。

## 十二、导出交互

- 「导出」在顶部导航展开二级菜单，面板对准「导出」挂件居中，并夹在视口左右边距内，禁止写死 `right` 贴视口右缘。设置面板同样对准「设置」挂件。两块以及登录/关于弹窗、笔菜单，统一 `--ease-pop` 缓动放大弹出，只带一次很小的回弹；点外面收起时轻轻缩回。
- 先选格式（Markdown / TXT / DOCX / PDF），再选范围（纯正文 / 正文+注释 / 正文+评论 / 全部）。
- 含问答题的文章额外提供「包含答案与解析」开关。
- 含讨论的导出显示快照时间。
- 点击后就地显示可取消的进度状态；完成即下载文件。
- **不弹出任何打印对话框。**
- 失败时说明具体是哪个组件或资源出问题，并让用户选择重试、分卷或仅导出正文，不把不完整文件说成「已全部导出」。

## 十三、文章列表页

- 书架/书屋气质，与首页线装书世界观连贯；卷册式卡片竖向排列，不用等宽网格瓷砖。
- 每张卡片：标题、摘要、日期、预计阅读时长、标签。
- 默认按发布时间倒序。
- 空状态使用编目中的书架意象，不显示空白页。
- 标签是否提供筛选界面见第十五节。

## 十四、交互原型文件

同目录下 [blog-reader-prototype.html](./blog-reader-prototype.html) 是本文的可点原型：

- 单文件、零依赖，浏览器直接打开即可，不需要构建也不联网。
- 覆盖上述全部视觉与交互：四套主题与隐去式滚动条（窗体最右侧与右栏彻底不画）、进页书册遮罩（颜色跟主题）、绳挂导航与渐隐及命中区、挂件悬停便笺、目录双模式（常驻挂签 / 一级标题 + 正文骨架 / 彩色微标）、正文全部内容块与降级卡片、划词工具条、注释高亮双向定位、右侧三页签与 Agent 外壳、右栏骨架懒载与缓出、整幅页尾评论区（首屏一页 / 到底收口 / 继续下滚拉出）、右侧悬浮小笔、通知（多张 / 左右随机 / 1 秒冷却 / 重力下落 / 悬停停住 / 点击撕碎）、分栏拖动、导出/设置菜单与弹窗的放大回弹、左右 Tab 短骨架切换、登录弹窗、移动端抽屉。
- **不接任何真实功能**：无后端、无持久化、无真实解析器、无真实导出。它只回答「长什么样、怎么动」。
- **实现 1:1 对标本文件**：布局、交互、视觉以原型为准，不得另起一套外观。文字说明与原型冲突时，先改本文对齐原型，再改实现；不要按本文自行发挥一套「更规范」的界面。
- **本文件也是全站 chrome 模板**：其它路由的通知、绳挂导航、弹窗、抽屉、滚动条、便笺，按这里已经画出来的那一套做，不先发明第二套。
- 颜色、字体、动效、z-index 仍走 `frontend-design.md` 的语义 token；原型里的硬编码色值只是示意，落地时映射到 token，不得另开一套配色。动效落地时补上 `--ease-damp`，曲线与原型一致。
