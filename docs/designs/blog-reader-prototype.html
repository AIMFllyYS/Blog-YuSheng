三体运动的混沌之美

2026-08-15约 12 分钟 天体力学混沌数值方法

引子：三个天体，一个难题

两个天体在引力下的运动可以写成闭合形式，r(θ) 是一条圆锥曲线，一切都优雅可控。可是只要再加进第三个天体，这份优雅就彻底消失了——不是因为方程变复杂了一点，而是因为解的性质发生了根本变化。

本文用一篇文章的篇幅走完三件事：先说清楚困难在哪，再看混沌在数学上长什么样，最后用一个可以在页面里拖动的数值实验把它显示出来。文中出现的 dt 都指积分步长。

从两体到三体

牛顿引力下 N 体系统的运动方程本身并不难写：

mi r̈i = ∑j≠i G mi mj rj − ri|rj − ri|3
难点从来不是写出方程，而是回答"这个方程的解长什么样"。而对三体问题，这个问题在一百多年里换了三次答案。

为什么没有解析解

  • 自由度增加使守恒量不足以把系统降到可积；
  • 庞加莱证明了不存在足够多的独立解析首次积分；
  • "无解析解"不等于"无法求解"，它只意味着必须换工具。

混沌的数学面貌

李雅普诺夫指数

两条初始相距 δ0 的轨道，其间距随时间的增长率给出了混沌的定量刻画：

λ = limt→∞ 1t ln δ(t)δ0
python
# 对同一初值加一个极小扰动，观察分离速度
def lyapunov(state, dt=1e-3, steps=200000):
    a, b = state, perturb(state, eps=1e-9)
    total = 0.0
    for _ in range(steps):
        a, b = step(a, dt), step(b, dt)
        d = distance(a, b)
        total += log(d / 1e-9)
        b = rescale(a, b, 1e-9)
    return total / (steps * dt)

  • Agent 外壳原型：上下文条、对话气泡、引用来源、建议提问、输入区，全部为示意
  • 整幅页尾评论区：三栏占满一屏，读到正文尽头后滚动链式传给文档，页尾带阻尼被拉出；波浪即左右栏终止线，与左右栏同底色
