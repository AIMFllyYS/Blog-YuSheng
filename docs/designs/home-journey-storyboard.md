# 首页 3D 叙事分镜节拍表（home-journey）

> Status: draft（待用户确认逐镜细节后转正）
> 决策背景：[architecture-overview.md](./architecture-overview.md) D11（固定视觉）/ D12（移动端降级）/ D17（Pretext 活字引擎）
> 实现归属：`src/features/home-journey/`

## 本轮已对齐的设定

| 项 | 结论 |
| --- | --- |
| 驱动方式 | 混合：滚动触发章节 + 越过临界点自动补完本章（磁吸到章节终点），可回滚倒放 |
| 第一屏 | 主文字 + 环境氛围（星空、金尘已在场） |
| 主文字 | 「羽升」+ 自题句「羽化成蝶 升生不息」 |
| 书的形象 | 线装古籍（宣纸质感、线装针脚） |
| 视觉基调 | 深夜星空 + 金光，固定一套不随主题切换（D11） |
| 入门落点 | 同页揭示主页本体（绳挂导航 + 板块入口），不跳转路由 |
| 重访策略 | 每次都播，右上角常驻「跳过」按钮 |
| 活字引擎 | Pretext（D17）：散开、汇聚、悬浮、游荡、文字雨全部走它算位置 |

## 总体结构

- 总滚动长度：约 **500vh 钉屏**（pin），四章 + 尾声，进度轴 0–100%
- 磁吸规则：进入某章超过其长度 **40%**（初始值，实现期调参）→ 自动补完至章终点；反向回滚同理
- 常驻 UI：右上「跳过 ⤍ 直接入门」；底部滚动提示（第一章启动后淡出）
- 无障碍：`prefers-reduced-motion` 直接呈现终态；移动端完全不进此流程（D12 卡片入口）

## 逐镜节拍表

### 序幕 · 静场（0%，未滚动的驻留态）

| 元素 | 状态 |
| --- | --- |
| 背景 | 深夜星空，金色尘埃粒子慢速漂浮，隐约星云 |
| 主标题 | 「羽升」大字居中（宋体系，墨金渐变） |
| 副句 | 「羽化成蝶 升生不息」小字一行，位于主标题下方 |
| 待机微动 | 逐字轻波浪浮动（Pretext wave），粒子慢漂——画面永远是活的 |
| 引导 | 底部滚动提示呼吸闪烁 |

### 第一章 · 散（0% → 25%）「文字附魔离散」

| 进度 | 镜头内容 |
| --- | --- |
| 0–3% | 滚动提示淡出；副句八字逐个亮起金边（预告要动的是它们） |
| 3–10% | 副句先散：字符逐个"附魔化"——字形闪变为篆书/符文样乱码，脱离行位飘起，各自游走 |
| 10–20% | 「羽升」二字裂解为笔画/字形粒子，向四周散开，粒子带金色拖尾；镜头开始微推近 |
| 20–25% | 全部字粒子被卷入一个缓慢旋涡。**章终点定格**：满屏星空 + 旋转的金色字粒涡流 |

### 第二章 · 聚（25% → 50%）「万字归书」

| 进度 | 镜头内容 |
| --- | --- |
| 25–32% | 涡流收紧，粒子加速向中心汇聚，中心亮度渐升 |
| 32–42% | 线装书成形：封面由粒子凝出宣纸纹理，书脊针脚逐针"缝"出（描线感） |
| 42–48% | 封面题字最后落定（书名**待定**，暂占位「羽升集」） |
| 48–50% | 镜头从正面绕至斜俯视。**章终点定格**：星空中悬浮一册闭合的线装书，金尘环绕 |

### 第三章 · 启（50% → 75%）「开卷活字」

| 进度 | 镜头内容 |
| --- | --- |
| 50–56% | 镜头下沉贴近书，封面掀开 |
| 56–66% | 书页加速翻动；**Pretext 主秀场**——字从页面浮起悬停书上，部分四处游荡，部分坠为文字雨落回页面 |
| 66–72% | 一句叙事文案在书上方逐字凝聚成行（**文案内容待定**） |
| 72–75% | 页心开始漏出金光，越翻越亮。**章终点定格**：书全摊开，中缝金光刺眼 |

### 第四章 · 门（75% → 100%）「众妙之门」

| 进度 | 镜头内容 |
| --- | --- |
| 75–82% | 最后一页翻过，金光暴涨占满全屏 |
| 82–88% | 光中凝出一道门形（光门），点题句浮现（**待定**，暂占位「玄之又玄，众妙之门」） |
| 88–95% | 门开，镜头穿门而过，白金闪光过渡 |
| 95–100% | **尾声揭示**：光散去，主页本体呈现——顶部绳索阻尼垂落到位（不回弹），卷轴/书挂件慢摆定位，板块入口逐个亮起。基调仍是深夜星空，UI 挂件按主题 token 着色，动效走全站阻尼语言（D11 / frontend-design 3.0） |

## 跳过与重访规则

- 跳过按钮 → 直接跳到 100% 终态（可加约 0.5s 的快闪过渡，不生硬切）
- 每次访问都从序幕开始，不做记忆
- 回滚：向上滚动即倒放，同样受章节磁吸约束

## 技术备注（实现期参考）

- GSAP ScrollTrigger：单条 master timeline + `pin` + `snap`（snap 点 = 各章终点），四章即四段 label
- 字粒子：Pretext `prepareWithSegments()/layoutWithLines()` 算家位置 → WebGL instanced sprites / DOM 层（按性能实测选）
- 跳过 = `timeline.progress(1)`；reduced-motion = 初始即 progress(1)
- 实现质量参照 `creating-ae-grade-gsap-motion` skill
