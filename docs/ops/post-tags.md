# 文章标签备忘

> 只给作者自己用的词表。**构建与运行时都不读本文**；漏写、写错、或 frontmatter 用了这里没有的词，都不会让 `pnpm build` 失败。
>
> 真正生效的是每篇 `content/posts/<slug>/index.md` 里的 `tags`。标签会显示在 `/blog/` 目录树的章行，以及书库里悬停小书脊后的书签旁边。没有筛选、没有标签页。

一篇小博客可以打 **1 到多个**标签；没有合适的就省略 `tags` 字段（不要写空数组）。优先用下表里的词；没有就自创，再用的时候回来补一行。单标签建议不超过约 12 个汉字。

大方向仍由 `section` 决定，标签不是第三层分类。

## 全栈小白学习记（`fullstack-learning`）

| 标签 | 何时用 |
|---|---|
| UI | 界面结构、视觉层级、组件长相 |
| UX | 交互路径、反馈、读起来费不费劲 |
| Agent | 智能体编排、工具调用、人机分工 |
| 架构设计 | 分层、边界、选型背后的理由 |
| Prompt | 提示词、上下文、怎么问模型 |

## AI-MFlly散记（`ai-mflly-notes`）

| 标签 | 何时用 |
|---|---|
| AI Coding | 用 AI 写代码、改代码、审代码 |
| AI生图 | 图像生成与修图工作流 |
| AI写作 | 用 AI 起稿、改稿、对照文风 |
| AI视频 | 视频生成、分镜、成片流程 |
| AI音乐 | 配乐、音色、生成音乐 |
| AI时代 | 不绑具体工具、谈这个时代本身 |

## 羽の反思 / 羽の复盘 / 羽の随笔 / 其他

这四本方向书共用下面这些词，按文章实际内容挑，不必每个方向都用遍。

| 标签 | 何时用 |
|---|---|
| 日常 | 具体的一天、一件小事 |
| 生活 | 比日常稍宽的起居与习惯 |
| 医学 | 健康、诊疗、循证相关的个人记录 |
| AI | 与模型/工具有关、但不必进散记那本 |
| 报告 | 课程作业、结业报告、正式书面总结 |
| 全栈开发 | 自己做的前后端/全栈实践，不必进学习记那本 |
| 教育 | 课程、教学产品、学习方法 |
| 社团 | 学校或组织里的社团 |
| 社群 | 线上或线下的一群人 |
| IP | 个人品牌、对外形象 |
| 人生 | 阶段、选择、长期课题 |
| 家庭 | 家人、亲缘、家里的事 |

## 怎么加新标签

1. 先在那篇 `index.md` 的 `tags` 里写上新词并发布预览。
2. 确认目录树和书签旁读得顺。
3. 再回到本表补一行，方便以后自己检索、也方便以后设计通用词。

不要为了「先登记」而阻塞发文。
