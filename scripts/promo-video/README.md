# 羽升集 · 30 秒宣传片

代码生成的博客宣传片：`composition.html` 逐帧绘制画面，`music.py` 合成配乐，`render.mjs` 用 Chromium 逐帧截图，再由 ffmpeg 合成 1920×1080 / 60fps / H.264 + AAC 的 MP4。

成片：`out/yusheng-blog-promo.mp4`

## 叙事

片子分三幕，走的是“独处的孩子 → 被时间定格 → 给自己取名 → 把自己写成书”这条线。素材全部来自 `content/`，没有另外编造人设。

| 幕 | 时间 | 情绪 | 视觉风格 | 素材出处 |
|---|---|---|---|---|
| 序 · 温情 | 0–12s | 慢、暖、阻尼 | 电影遮幅 2.35:1、胶片颗粒、深空金尘 | 《回归本真》《毕业升学 · 一寸光阴的曾经》、首页 motto、《一份中二的自我介绍》 |
| 书 · 卡点 | 12–26s | 快、硬切、每拍一动 | 宣纸书架 → 深空时间线 → 8 种海报风格 → 报纸墙 | `sections.yml` 七卷、36 篇正式文章、38 份折晓早报 |
| 光 · 回落 | 26–30s | 收、留白 | 金光爆开、3D 书《羽升集》、遮幅合上 | 首页 `JOURNEY_CONTENT.narrative`、“不问前程，尽管繁荣” |

## 渲染

依赖不进项目 `package.json`，在工作目录里单独安装：

```bash
# 任意目录
npm i playwright-core @fontsource/noto-serif-sc @fontsource/ma-shan-zheng @fontsource/jetbrains-mono
pip install numpy scipy

# 本目录
python3 music.py out/music.wav
PROMO_DEPS=<上面的目录> FFMPEG=<ffmpeg 路径> node render.mjs              # 全片
PROMO_DEPS=<上面的目录> node render.mjs --stills 5.8,12.1,20.3            # 抽静帧检查
```

- Chromium 默认用 `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`，可以用 `CHROMIUM` 覆盖
- 画面是 `t` 的纯函数（随机数全部带种子），所以任意一帧都能单独重渲，结果一致
- 视频按 6 Mbps 编码（胶片颗粒很吃码率，控制成片在 25 MB 以内）；音频整体 -3 dB，约 -14 LUFS
- `out/` 里只提交成片 MP4；`music.wav` 和静帧可以随时重新生成
